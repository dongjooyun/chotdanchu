# 활용한 외부 자원·출처 (제출용 초안)

제출 서류의 「활용한 외부 자원·출처」 표가 된다. 새 데이터, API, 라이브러리, 이미지, 폰트를 쓰면 바로 한 줄 추가한다.

## 쓰지 않는 것

- 잡플래닛, 블라인드, 원티드, 사람인, 잡코리아 등 민간 플랫폼 데이터 (크롤링 금지, 원문 링크만)
- theVC, 혁신의숲, 네이버 증권 (원문 링크만)
- 벤처기업 확인 정보 (기업별로 조회할 공공 데이터가 없음)
- 실제 개인의 이력서·포트폴리오
