## 쓰지 않는 것

- 잡플래닛, 블라인드, 원티드, 사람인, 잡코리아 등 민간 플랫폼 데이터 (크롤링 금지, 원문 링크만)
- theVC, 혁신의숲, 네이버 증권 (원문 링크만)
- 벤처기업 확인 정보 (기업별로 조회할 공공 데이터가 없음)
- 실제 개인의 이력서·포트폴리오
