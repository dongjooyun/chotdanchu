# 활용한 외부 자원·출처 (제출용 초안)

제출 서류의 「활용한 외부 자원·출처」 표가 된다. 새 데이터, API, 라이브러리, 이미지, 폰트를 쓰면 바로 한 줄 추가한다.

| 구분 | 이름 | 링크 | 용도 | 라이선스·이용 조건 | 상태 |
|---|---|---|---|---|---|
| API | OpenDART (금융감독원 전자공시) | https://opendart.fss.or.kr | 기업개황, 재무, 사업보고서 | 무료, 인증키 필요, 일일 호출 제한 확인 | 키 발급 전 |
| 공공데이터 | 국민연금공단 가입 사업장 내역 | https://www.data.go.kr | 고용 흐름, 급여 추정 | 공공누리 조건 확인 | 확인 필요 |
| 공공데이터 | 공공기관 채용정보 조회서비스 | https://www.data.go.kr (15125273) | 공공기관 공고 | 확인 필요 | 확인 필요 |
| 공공데이터 | 국세청 사업자 상태 조회 | https://www.data.go.kr | 휴폐업 확인 | 확인 필요 | 확인 필요 |
| 공공데이터 | 고용노동부 체불사업주 명단 | 확인 필요 | 리스크 지표 | 확인 필요 | 확인 필요 |
| AI | Anthropic Claude API | https://docs.claude.com | 에이전트 판단, 역량 추출, 리포트 문장 | 유료, 상업 이용 약관 | 사용 예정 |
| 개발 도구 | Claude Code | https://docs.claude.com | 코드 작성 보조 | | 사용 중 |

## 쓰지 않는 것

- 잡플래닛, 블라인드, 원티드, 사람인, 잡코리아 등 민간 플랫폼 데이터 (크롤링 금지, 원문 링크만)
- theVC, 혁신의숲, 네이버 증권 (원문 링크만)
- 실제 개인의 이력서·포트폴리오
