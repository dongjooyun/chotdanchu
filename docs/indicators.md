# 10가지 지표 (초안)

등급은 A, B, C, 그리고 근거가 없으면 `확인 불가`. 기준값은 KT 아카데미 기업분석 수업의 기준을 출발점으로 하고, 구현하며 조정한다.

| 지표 | 무엇을 보나 | 주 출처 | 초안 기준 | 비공시 기업 |
|---|---|---|---|---|
| 재무 체력 | 버틸 힘 | OpenDART 재무 | 부채비율 300% 이상이면 위험 | 외감이면 감사보고서, 아니면 확인 불가 |
| 성장성 | 크고 있는가 | OpenDART 재무 | 매출 연 15% 이상 성장이면 높음 | 동일 |
| 수익성 | 돈을 버는가 | OpenDART 재무 | 1인당 영업이익 3,000만 원 이상이면 높음 | 동일 |
| 고용 흐름 | 사람이 늘고 있나 | 국민연금 가입 사업장 | 12개월 가입자 증감 | 3인 이상 법인은 대부분 가능 |
| 보상 | 급여 수준 | 국민연금 고지금액 기반 추정, DART 급여총액 | 추정치는 범위로 표시 | 추정만 가능 |
| 근속 | 오래 다니는가 | DART 사업보고서 평균 근속 | 업종 평균 대비 | 확인 불가가 많음 |
| 기술 투자 | 배울 거리 | DART 연구개발비 | 매출 대비 R&D 5% 이상이면 높음 | 확인 불가가 많음 |
| 투자 단계 | 스타트업 단계 | 공식 출처 없음 | 원문 링크만 제공 | 확인 불가 |
| 리스크 | 위험 신호 | 공공 명단(임금체불 등, 확인 필요), 휴폐업 조회 | 해당 여부 | 가능 |
| 정보 투명도 | 위 9개 중 확인된 비율 | 자동 계산 | 7/9 이상이면 A | 항상 계산 |

## 원칙

- 등급 계산은 전부 코드. LLM은 등급을 바꾸지 않는다.
- 모든 값에 출처와 기준 시점을 붙인다.
- 업종 내 순위는 선택 기능. 넣는다면 "공시 기업 N곳 중 상위 x%"처럼 모집단을 같이 쓴다.
