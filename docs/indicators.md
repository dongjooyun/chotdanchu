# 10가지 지표와 등급 기준 (11/19 확정)

등급은 A, B, C, 그리고 근거가 없으면 `확인 불가`. 기준값은 **KT 기업분석 수업(0824~0827) 기준을 그대로** 쓰고, 수업에 없는 값만 팀이 근거와 함께 정했다. 기업 성격(스타트업, 일반 기업)마다 기준표를 따로 쓴다. 기업 유형 정의와 "왜 확인 불가인지"는 노션 PRD 04에 있다.

데이터 모양은 [`schema.md`](schema.md), 지표 id는 `lib/types.ts`.

## 원칙

- 등급 계산은 전부 코드. LLM은 등급을 바꾸지 않는다.
- 모든 값에 출처와 기준 시점을 붙인다.
- 어느 기준표의 어느 기준으로 매겼는지(`basis`)를 카드에 보여준다.
- 경계값은 위쪽 등급에 넣는다 (예: 부채비율이 정확히 100%면 B, 매출 증가율이 정확히 15%면 A).

| 성장성 (`revenue_growth` 매출 증가율) | 연 15% 이상 | 0~15% | 감소 | KT: 연 15% 이상이면 성장성 좋음. 감소는 사업 위축 신호 | OpenDART 재무 |
| 수익성 (`operating_margin` 영업이익률) | 7% 이상 | 3~7% | 3% 미만 | KT: 7~10% 이상 알짜, 제조 평균 3~5%, 1~2%면 남는 게 없음. 1인당 영업이익(3,000만 원 기준)은 보조 수치 | OpenDART 재무 |

| 기술 투자 (`rnd_ratio` 매출 대비 R&D) | 업종 적정 범위 위 | 범위 안 | 범위 아래 | KT 업종별 적정 비율 그대로 (아래 표) | 사업보고서 본문 "연구개발활동" (재무 API에 계정이 없어 시연 기업만 수동 확인) |
| 투자 단계 | 등급 없음 | | | 일반 기업은 투자 라운드로 판단하지 않음 | |
| 리스크 | 해당 없음 | 감사의견 한정 등 경미 | 휴폐업, 감사의견 부적정 또는 거절 | 휴폐업은 바로 위험, 한정 의견은 주의 | 국세청 사업자 상태, DART 감사의견 |

### 기술 투자 업종 구간 (KT 기준)

| 업종 구간 | 대표 업종 | 적정 R&D 비율 |
|---|---|---|
| 기술 집약 | 바이오·제약, AI·소프트웨어, 시스템 반도체 | 10~20% |
| 첨단 제조 | 반도체 장비, 디스플레이, 뷰티 테크, 이차전지 | 5~10% |
| 전통 제조·장치 | 석유화학, 철강, 자동차 부품 | 1~3% |
| 서비스·금융·유틸리티 | 신용평가, 에너지, 인프라, 플랫폼 서비스 | 0.1~1% |

업종 구간은 표준산업분류(KSIC) 코드로 코드가 정한다.

## 스타트업 기준표 (KT "알짜 스타트업 최소 합격 기준")

| 지표 (metric) | A | B | C | 근거 | 주 출처 |
|---|---|---|---|---|---|
| 고용 흐름 (`headcount_change_12m`, 월 퇴사율) | 입사 > 퇴사이고 월 퇴사율 3% 이하 | 그 외 | 인원 감소 또는 월 퇴사율 5% 초과 | KT: 월 3% 이하(연 20%). 5%는 기준선보다 확실히 나쁜 구간 | 국민연금 가입 사업장 |
| 보상 (`avg_salary`) | 업종 평균보다 10% 이상 높음 | ±10% 이내 | 10% 이상 낮음 | KT: 동종·규모 평균 대비 상위 | 국민연금 고지금액 기반 추정 |
| 기술 투자 (`registered_patents` 등록 특허) | 3건 이상 | 1~2건 | 0건 | KT: 출원이 아니라 등록 3건 이상 | 특허청 KIPRIS Plus |
| 성장성 (`revenue_growth`, 외감일 때) | 연 50% 이상 | 0~50% | 감소 | KT: 매출 연 50% 이상 우상향 | 감사보고서 (OpenDART) |
| 수익성 (`operating_income`, 외감일 때) | 영업흑자 (손익분기 달성) | 적자폭 축소 | 적자폭 확대 | KT: 손익분기 달성이면 통과. 스타트업은 적자 여부보다 방향이 중요 | 감사보고서 (OpenDART) |
| 재무 체력 (`runway_months` 런웨이, 외감일 때) | 18개월 이상 | 12~18개월 | 12개월 미만 | KT: 최소 1.5년 런웨이. 1년 미만이면 다음 투자가 급함 | 감사보고서 (OpenDART) |
| 투자 단계 (`cumulative_funding`, 라운드, 최근 투자 시점) | ①과 ② 모두 충족 | 하나만 충족 | 둘 다 미충족 | KT 알짜 스타트업 기준. 시연 기업만 공식 발표 수동 확인, 못 찾으면 확인 불가 | 기업·투자사 공식 발표 (수동) |
| 근속 | 사업보고서를 내는 비상장이면 일반 기업과 같은 기준, 아니면 확인 불가 | | | 평균 근속은 사업보고서(직원 현황)에만 있음 | OpenDART 직원 현황 |
| 리스크 | 일반 기업과 같음 | | | | |

투자 단계의 조건: ① 라운드와 누적 투자금 (시리즈 A면 누적 30억 원 이상, 시리즈 B 이상이면 100억 원 이상) ② 최근 투자 유치가 18개월 이내.

외감이 아닌 스타트업의 재무 체력, 성장성, 수익성은 `확인 불가`(`not_disclosed`)다.

## 정보 투명도 (두 기준표 공통)

나머지 9개 지표 중 확인된(등급이 나온) 개수. 7개 이상 A, 4~6개 B, 3개 이하 C. 일반 기업은 투자 단계에 등급이 없으므로 8개 중에서 센다.

## 보조 신호 (등급에 넣지 않음)

- 이노비즈·메인비즈 인증, 워크넷 강소기업 (중소기업 판단 보조)
- 직원 수, 유보율, 1인당 영업이익
- 고용노동부 체불사업주 명단: 자동 처리하지 않는다. 시간이 남으면 시연 기업만 사람이 확인하고, 명단의 개인 이름은 저장하거나 LLM에 넣지 않는다
