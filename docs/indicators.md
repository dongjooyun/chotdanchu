# 10가지 지표와 등급 기준 (11/19 확정)

등급은 A, B, C, 그리고 근거가 없으면 `확인 불가`. 기준값은 **팀이 공개된 기업분석 자료와 실측(OpenDART, 국민연금)을 바탕으로 자체 리서치해 정한 기준**이다. 근거 칸에는 왜 그 값인지만 적는다. 기업 성격(스타트업, 일반 기업)마다 기준표를 따로 쓴다. 기업 유형 정의와 "왜 확인 불가인지"는 노션 PRD 04에 있다.

데이터 모양은 [`schema.md`](schema.md), 지표 id는 `lib/types.ts`.

## 코드

- 등급 계산은 `lib/indicators.ts`의 `computeIndicators(company, asOf)`. 원시값을 받아 10개 등급(정보 투명도 포함)을 돌려준다. `asOf`는 투자 18개월을 셀 기준일이다
- 테스트는 `tests/unit/indicators.test.ts`. `npm test`로 돌린다. 기준표 한 줄마다 경계값 케이스가 있고, 기준값을 바꾸면 테스트와 추적표도 같이 고친다 ([`testing.md`](testing.md))
- 일반 기업의 투자 단계는 데이터가 있든 없든 "등급 없음"이고, 확인 불가로 세지 않는다

## 원칙

- 등급 계산은 전부 코드. LLM은 등급을 바꾸지 않는다.
- 모든 값에 출처와 기준 시점을 붙인다.
- 어느 기준표의 어느 기준으로 매겼는지(`basis`)를 카드에 보여준다.
- 경계값은 위쪽 등급에 넣는다 (예: 부채비율이 정확히 100%면 B, 매출 증가율이 정확히 15%면 A).

## 일반 기업 기준표 (대·중견·중소)

| 지표 (metric) | A | B | C | 근거 | 주 출처 |
|---|---|---|---|---|---|
| 재무 체력 (`debt_ratio` 부채비율) | 100% 미만 | 100~300% | 300% 이상 | 300% 이상 위험 신호, 100%면 자기자본만큼 빚. 유보율(1000%↑ 알짜, 500%↑ 안정)은 보조 수치 | OpenDART 재무 |
| 성장성 (`revenue_growth` 매출 증가율) | 연 15% 이상 | 0~15% | 감소 | 연 15% 이상이면 성장성 좋음. 감소는 사업 위축 신호 | OpenDART 재무 |
| 수익성 (`operating_margin` 영업이익률) | 7% 이상 | 3~7% | 3% 미만 | 7~10% 이상 알짜, 제조 평균 3~5%, 1~2%면 남는 게 없음. 1인당 영업이익(3,000만 원 기준)은 보조 수치 | OpenDART 재무 |
| 고용 흐름 (`headcount_change_12m`, 연 퇴사율) | 인원 순증이고 연 퇴사율 20% 이하 | 그 외 | 12개월 인원 10% 이상 감소 | 꾸준히 플러스면 좋음, 퇴사율 20% 이하, 급격한 감소는 위험. "급격"을 연 10%로 수치화 | 국민연금 가입 사업장 |
| 보상 (`avg_salary` 평균 연봉 추정) | 업종 평균보다 10% 이상 높음 | ±10% 이내 | 10% 이상 낮음 | 같은 업종 평균과 비교. 국민연금 추정 오차를 감안해 ±10%는 같은 수준으로 봄. 범위의 가운데값으로 비교 | 국민연금 고지금액 기반 추정 |
| 근속 (`avg_tenure` 평균 근속, 사업보고서 제출 법인만) | 10년 이상 | 5~10년 | 5년 미만 | 장기근속으로 꼽히는 기업은 15년 안팎. 5년 미만이면 "3년 뒤" 선배가 드물 가능성 | OpenDART 직원 현황 |
| 기술 투자 (`rnd_ratio` 매출 대비 R&D) | 업종 적정 범위 위 | 범위 안 | 범위 아래 | 업종마다 적정 비율이 다르다 (아래 표) | 사업보고서 본문 "연구개발활동" (재무 API에 계정이 없어 시연 기업만 수동 확인) |
| 투자 단계 | 등급 없음 | | | 일반 기업은 투자 라운드로 판단하지 않음 | |
| 리스크 | 해당 없음 | 감사의견 한정 등 경미 | 휴폐업, 감사의견 부적정 또는 거절 | 휴폐업은 바로 위험, 한정 의견은 주의 | 국세청 사업자 상태, DART 감사의견 |

## 스타트업 기준표 (첫 회사로 고를 만한 스타트업의 최소 기준)

| 지표 (metric) | A | B | C | 근거 | 주 출처 |
|---|---|---|---|---|---|
| 고용 흐름 (`headcount_change_12m`, 월 퇴사율) | 입사 > 퇴사이고 월 퇴사율 3% 이하 | 그 외 | 인원 감소 또는 월 퇴사율 5% 초과 | 월 3% 이하(연 20%). 5%는 기준선보다 확실히 나쁜 구간 | 국민연금 가입 사업장 |
| 보상 (`avg_salary`) | 업종 평균보다 10% 이상 높음 | ±10% 이내 | 10% 이상 낮음 | 같은 업종 평균과 비교 | 국민연금 고지금액 기반 추정 |
| 기술 투자 (`registered_patents` 등록 특허) | 3건 이상 | 1~2건 | 0건 | 출원이 아니라 등록 3건 이상 | 특허청 KIPRIS 웹사이트 (시연 기업만 사람이 검색해 "수동 확인", 그 밖의 기업은 확인 불가) |
| 성장성 (`revenue_growth`, 외감일 때) | 연 50% 이상 | 0~50% | 감소 | 매출 연 50% 이상 우상향 | 감사보고서 (OpenDART) |
| 수익성 (`operating_income`, 외감일 때) | 영업흑자 (손익분기 달성) | 적자폭 축소 | 적자폭 확대 | 손익분기 달성이면 통과. 스타트업은 적자 여부보다 방향이 중요 | 감사보고서 (OpenDART) |
| 재무 체력 (`runway_months` 런웨이, 외감일 때) | 18개월 이상, 또는 영업흑자 | 12~18개월 | 12개월 미만 | 최소 1.5년 런웨이. 1년 미만이면 다음 투자가 급함. 런웨이 = 현금및현금성자산 / (영업손실 / 12). 영업흑자면 현금을 소진하지 않아 런웨이 제한이 없으므로 A (11/21 결정, `extra.profitable`) | 사업보고서·감사보고서 (OpenDART) |
| 투자 단계 (`cumulative_funding`, 라운드, 최근 투자 시점) | ①과 ② 모두 충족 | 하나만 충족 | 둘 다 미충족 | 투자 규모와 최근성을 함께 본다. 시연 기업만 공식 발표 수동 확인, 못 찾으면 확인 불가 | 기업·투자사 공식 발표 (수동) |
| 근속 | 사업보고서를 내는 비상장이면 일반 기업과 같은 기준, 아니면 확인 불가 | | | 평균 근속은 사업보고서(직원 현황)에만 있음 | OpenDART 직원 현황 |
| 리스크 | 일반 기업과 같음 | | | | |

투자 단계의 조건: ① 라운드와 누적 투자금 (시리즈 A면 누적 30억 원 이상, 시리즈 B 이상이면 100억 원 이상) ② 최근 투자 유치가 18개월 이내.

외감이 아닌 스타트업의 재무 체력, 성장성, 수익성은 `확인 불가`(`not_disclosed`)다.

## 정보 투명도 (두 기준표 공통)

나머지 9개 지표 중 확인된(등급이 나온) 개수. 7개 이상 A, 4~6개 B, 3개 이하 C. 일반 기업은 투자 단계에 등급이 없으므로 8개 중에서 센다.

## 국민연금 데이터 사용 규칙 (11/19 실측)

- 원본은 월 1회 갱신되는 CSV(CP949). 기업은 OpenDART 기업개황의 사업자번호 앞 6자리와 사업장명 일부가 모두 같은 행으로 찾는다. 이름만으로는 다른 회사가 섞인다.
- 고용 흐름의 주 수치는 가입자수의 12개월 증감(최신 파일과 약 12개월 전 파일 비교). 신규취득자수와 상실가입자수는 한 달치 값이고 "전달과 이번 달 고지 대상 비교"라서 변동이 크다. 월 상실률(상실/가입자수)은 보조 수치로만 표시하고 "추정"을 붙인다.
- 보상 추정은 `당월고지금액 / 가입자수 / 0.09 * 12`로 계산한 연 소득의 하한 추정이다. 기준소득월액 상한(2026.7~2027.6 월 659만 원) 근처이면 "추정 이상"으로 표시한다. 업종 평균은 같은 파일에서 같은 업종코드 사업장(가입자수 3명 이상, 가입 상태 등록)의 가중평균으로 코드가 계산한다. 업종코드가 비어 있는 사업장은 OpenDART 기업개황의 업종코드를 쓴다.
- 대상은 가입자 3인 이상 법인, 10인 이상 개인사업장이다. 파일에서 찾지 못하면 고용 흐름과 보상은 `확인 불가`로 둔다.

## 보조 신호 (등급에 넣지 않음)

- 이노비즈·메인비즈 인증, 워크넷 강소기업 (중소기업 판단 보조)
- 직원 수, 유보율, 1인당 영업이익
- 고용노동부 체불사업주 명단: 자동 처리하지 않는다. 시간이 남으면 시연 기업만 사람이 확인하고, 명단의 개인 이름은 저장하거나 LLM에 넣지 않는다
