첫 회사 발판 에이전트: 핵심 기능 흐름

대화형 에이전트 한 화면 안에서 진행되는 순서입니다. 파란 상자만 LLM이 스스로 판단하는 단계이고, 나머지는 사용자 입력이나 코드가 처리합니다. 2026-11-08 초안.

사용자 행동에이전트 판단 (LLM)코드 · 데이터 (결정적)반복 · 저장소

단계별로 에이전트가 판단하는 것

단계LLM이 정하는 것코드가 정하는 것범위
1 선호 파악가중치를 사람이 읽는 유형 설명으로 바꾸기카드 쌍 출제, 쌍 비교 가중치 계산필수
2 기업 특정입력이 어느 법인을 가리키는지, 후보를 몇 곳 보여줄지OpenDART 기업개황 조회필수
3 기업 실사기업 유형(상장, 외감, 비공시, 공공기관)에 따라 어떤 출처를 부를지지표 계산, 근거 없는 칸은 확인 불가 표시필수 업종 내 순위는 선택
4 커리어 가늠3년차 공고가 없을 때 어떤 유사 기업으로 대체할지, 역량 추출과 정규화공고 수집, 역량 사전 매칭필수
5 판단 리포트지표와 선호, 성장 갭을 엮은 조언과 면접 역질문리포트 레이아웃, 출처 링크필수

제외한 것

이력서, 포트폴리오, 기업 후기는 입력 소스로 쓰지 않습니다(개인정보 규정 제7조, 후기 크롤링 법적 위험). 회원가입, 로그인, 마이페이지, 이메일 발송도 이번 범위에서 뺍니다.
